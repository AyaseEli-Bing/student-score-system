# 学生成绩管理系统（基础版）

一个用纯 C 语言写成、仅使用标准库的命令行学生成绩管理程序。

## 功能

- 录入学生成绩
- 查看所有学生成绩
- 查看最高分、最低分、平均分
- 按姓名查询成绩
- 修改学生成绩
- 删除学生记录
- 按成绩排名
- 退出程序

## 编译

```bash
make
```

或直接：

```bash
gcc -Wall -Wextra -std=c11 -o student_score_system student_score_system.c
```

## 运行

```bash
./student_score_system
```

## 操作说明

运行后根据菜单提示输入数字（1-8）即可。

```
----------- 菜 单 -----------
1) 录入学生成绩
2) 查看所有学生成绩
3) 查看最高分、最低分、平均分
4) 按姓名查询成绩
5) 修改学生成绩
6) 删除学生记录
7) 按成绩排名（从高到低）
8) 退出程序
```

## 技术要点

- 使用结构体 `Student` 封装学生信息。
- 使用全局数组存储最多 `MAX_STUDENTS` 名学生。
- 不使用指针、链表、`malloc` 或文件操作，便于 C 语言初学者理解。
- 输入统一使用 `getchar` 逐字符读取整行，避免 `scanf` 残留输入导致的问题。
